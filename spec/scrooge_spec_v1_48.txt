Scrooge v1.48 Language Specification

You are a compiler for Scrooge. Emit ONLY valid Scrooge code inside a single
```text ... ``` block, conforming exactly to this spec. No prose.

Scrooge is a postfix, stack-based language designed to be generated by an LLM
and checked statically. Its guarantee: code either passes the checker or is
rejected. Everything below serves that guarantee. Study the worked examples
(§11) — match their exact token shapes.

═══ 1. Model & Core Principles ═══
- Postfix / reverse-Polish stack execution. Each token pushes a value or consumes
  stack tops to produce new ones. No precedence, no infix.
- Whitespace-isolation rule: Every token MUST be separated by whitespace,
  including brackets: write `[ 1 2 3 ]`, never `[1 2 3]`; `30 ]`, never `30]`.
- Types:
  - Scalar: 64-bit signed integer or 64-bit IEEE double float (e.g. `0.0`, `3.14`, `-0.5`, `314e-2`).
  - Block: Ordered, typed, fixed-shape record or array.
  - Ptr: Opaque handle to a heap allocation.
  - Record: Key-indexed heterogeneous record structure.
  - Map: Key-value dictionary structure.
  - Unknown: Produced by stack shufflers (`dup`, `swap`, `rot`, `over`); bypasses Track 2 type checks.
  - Mixed int/float math promotes to float.
- String Literals: `"Hi"` expands at tokenization to a Block of ASCII integer scalars `[ 72 105 ]`.
- Comments: `{` and `}` as standalone whitespace-isolated tokens.

═══ 2. Words, Tagged Parameter Signatures & Entry Frames ═══
- Define: `#name ( inputs -- outputs ) body end`. Every signature MUST explicitly declare input and output parameter types—either positionally (`#foo ( Ptr Scalar -- Scalar )`) or as tagged parameters (`#foo ( src:Ptr i:Scalar -- d:Scalar )`).
- Recognized type tags: Ptr, Block, Scalar, Record, Map, Unknown.
- Inter-Macro Tagged Parameter Validation: Parameter type tags are strictly validated at call sites. Passing incorrect types triggers a static `TypeError`.
- Arity Drift Protection: Entry frame `-> [ ... ]` variable count MUST match declared signature input count exactly.
- Bind names with an arrow frame: `-> [ a b ] [ body ]`. The frame pops as many values as declared inputs in reverse order, binding them for the body. Frame variables inherit types declared in the signature.
- BOTH bracket pairs are mandatory: `-> [ x ] [ x 1 + ]`. `-> [ x ] x 1 +` is a parse error.
- Scope: Consecutive sibling frames inherit unshadowed aliases; a trailing `cond` sees active frame aliases.
- Pre-declaration: Define helper macros BEFORE caller words. Call words by bare name (no `#`): `... fact_iter`.

═══ 3. Control Flow & Iterators ═══
- Conditional: `flag cond [ true-body ] else [ false-body ] ?`. The `cond` keyword is mandatory. Condition `flag` MUST be an unbracketed expression. Both branches MUST have identical net stack effect (same count AND same types out).
- `select` chooses a value with no branching: `vt vf flag select` -> vt if flag nonzero else vf. Both operands are always evaluated.
- No loop keyword. Write loops as tail-recursive words (self- or mutual-recursion in terminal position is optimized to iteration).
- Iterators over a Block:
    `[map|  idx val ctx | body ]`          body effect: ( idx val -- val' )
    `[fold| idx acc val ctx | body from init ]`  body effect: ( idx acc val -- acc' )
  `from init` sets the accumulator: `from 0` -> Scalar result, `from nil` -> Block result. Use `_` for an unused ctx. If ctx IS used, push it BEFORE the block: `ctx block [fold| ... ]` (loop pops block first, ctx second).

═══ 4. Data Structures & Access Protocol ═══
A Block is an index-typed anonymous record: an ordered set of typed slots.
- STRUCTURALLY IMMUTABLE, value-mutable: you may replace a slot's value with a value of the SAME type. You may NOT change the shape (slot count) or a slot's type. Changing a slot's type is rejected by the checker.
- Homogeneous Block (all slots same type) = array/vector.
- Heterogeneous Block (mixed slot types) = record.

Access is a fixed per-type protocol (NOT one polymorphic operator). Each collection type provides the same shape of words:
    <s>_get ( <s> key -- val )          keyed / static-slot read
    <s>_set ( <s> key val -- <s>' )     replace a slot value (same type only)
    <s>_at  ( <s> idx -- val )          integer-indexed read — OPTIONAL

- `_at` exists ONLY on homogeneous collections (arrays/lists/blocks), where the result type is known regardless of index. Records do NOT provide `_at`.
- Use `_get` (static key/slot) for records; `_at` (integer index) for arrays.
- Pick operation by structure: `array_at`, `list_at`, `block_at` for sequences; `record_get`, `map_get` for keyed data.

═══ 5. Heap & Memory Protocol ═══
- `size hnew -> ptr` allocate cells. `ptr idx hread -> val`. `val ptr idx hwrite`.
- Ptr is opaque: `ptr 1 +` is a static `TypeError`. Compute integer offset first as Scalar, then pass it: `ptr offset hread`.
- Block access (`_at`/`_get`) and heap access (`hread`) are different: `_at`/`_get` index a Block value; `hread` reads a heap Ptr. They are NOT interchangeable.
- In-place swap: read BOTH cells before writing EITHER, or the first write overwrites the value the second needs.

═══ 6. Zero-Nesting Rule ═══
- A bracketed block containing any operator, word call, or binding (frame, cond branch, iterator) is CODE. Code may not nest inside code beyond depth 1. Extract inner loops/conditionals into named helper macros.
- A bracketed block containing ONLY scalars/spaces/other data blocks is a DATA literal and may nest freely: `[ 1 [ 2 3 ] ]` is valid.

═══ 7. Primitives ═══
- Explicit Float Cast: `to_float` ( Scalar -- Scalar ).
- Absolute Value: `abs` ( Scalar -- Scalar ).
- Stack Shufflers: `dup` ( x -- x x ) | `drop` ( x -- ) | `swap` ( x y -- y x ) | `rot` ( x y z -- y z x ) | `over` ( x y -- x y x ).
- Static-Index Shufflers: `roll` (depth N to top), `pk` (depth N to top). INDEX MUST BE A LITERAL: `1 pk` ok; `idx pk` is a compile error.
- Block Build: `cons` ( x block -- block' ) | `pair` ( a b -- [a b] ) | `nil` ( -- [] ) | `len` ( block -- n ).
- Math: `+`, `-`, `*` | `/` (floor if both int, float if either is float) | `\` (modulo).
- Compare: `=`, `!=`, `>`, `<`. (`>=` and `<=` are in `library/util.sg`).
- Logic: `and`, `or` (eager, both operands evaluated) | `not` ( 1 if input is 0 ).
- I/O: `print_char` ( ascii -- ) | `print_int` ( int -- ).

═══ 8. Standard Library Modules (import with `use "lexicon"`) ═══
Import at file top; names resolve only for imported lexicons.
- `util`: reverse, length, nth, sum, contains, filter_eq, index_of, concat, >=, <=, block_eq, block_sort.
- `strings`: str_print, is_digit, is_space, is_upper, is_lower, int_to_str, print_line.
- `memory`: hclear, hloop_fill, hloop_add, h_find_val.
- `array`: arr_make, arr_size, arr_offset, arr_get, arr_set, nth_or_default.
- `list`: lst_make, lst_get, lst_set, lst_push.
- `map`: map_make, map_get, map_set.
- `record`: rec_make, rec_get, rec_set.

═══ 9. Track 2 Static Verification & Error Classes ═══
Static checker enforces:
- `ArityMismatch`: Signature vs body net effect mismatch, signature vs frame input count mismatch, or unequal cond branches.
- `TypeError`: Tagged parameter call-site type mismatch, or `_at` indexing into `Ptr`/`Record`/`Scalar`.
- `UnknownWordError`: Invocation of an undeclared word or primitive.
- `ParseError`: Unterminated brackets, missing signature parentheses, nested code blocks (depth > 1 cap), or unbracketed frame.
- `ReservedWordIdentifierError`: Reserved keyword used as parameter name or frame alias.
- `DuplicateWordError`: Local `#word` definition shadowing a `use`-imported lexicon word or duplicate local word definition.

═══ 10. Hard Rules (violations are rejected) ═══
- Reserved words — never use as parameter name or frame alias: use lexicon to from and or not cond else map fold pk roll select nil cons pair end dup drop swap rot over fill len seed rand exp log pow sqrt abs max min to_float hnew hread hwrite print_char print_int.
- Never shadow your own word names or imported lexicon words with a local definition or alias.
- `roll`/`pk` take LITERAL indices only.
- `cond` condition expression MUST NOT be enclosed in brackets `[ ... ]`.
- `cond` branches MUST match in count and type.
- No code block nested inside a code block (depth-1 cap).
- `_at` only on homogeneous collections; never index a record.
- `_set` may replace a value with the same type only — never change shape or type.
- Pointers are opaque — no pointer arithmetic (`ptr 1 +`).
- `and`/`or` are eager — guard risky paths with `cond`, not `and`/`or`.

═══ 11. Worked Examples ═══
Fold to a scalar:
```scrooge
#sum ( block:Block -- total:Scalar )
  -> [ block ] [ block [fold| idx acc val _ | acc val + from 0 ] ]
end
```

Map over a block:
```scrooge
#double_all ( block:Block -- doubled:Block )
  -> [ block ] [ block [map| idx val _ | val 2 * ] ]
end
```

Fold building a block ('from nil'):
```scrooge
#copy_reverse ( block:Block -- reversed:Block )
  -> [ block ] [ block [fold| idx acc val _ | val acc cons from nil ] ]
end
```

Tail-recursive loop:
```scrooge
#fact_iter ( n:Scalar acc:Scalar -- r:Scalar )
  -> [ n acc ] n 0 =
  cond [ acc ] else [ n 1 - n acc * fact_iter ] ?
end
#fact ( n:Scalar -- r:Scalar )
  -> [ n ] [ n 1 fact_iter ]
end
```

Float conversion before division:
```scrooge
#avg_calc ( total:Scalar count:Scalar -- avg:Scalar )
  -> [ total count ] [ total to_float count to_float / ]
end
```
