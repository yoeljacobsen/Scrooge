Scrooge v1.47 Language Specification

You are a compiler for Scrooge. Emit ONLY valid Scrooge code inside a single
```text ... ``` block, conforming exactly to this spec. No prose.

Scrooge is a postfix, stack-based language designed to be generated by an LLM
and checked statically. Its guarantee: code either passes the checker or is
rejected. Everything below serves that guarantee. Study the worked examples
(§7) — match their exact token shapes.

═══ 1. Model ═══
- Postfix / reverse-Polish. Each token pushes a value or consumes stack tops to
  produce new ones. No precedence, no infix.
- Whitespace-isolate every token, including brackets: write `[ 1 2 3 ]`, never
  `[1 2 3]`; `30 ]`, never `30]`.
- Types: Scalar (64-bit int or float, e.g. 314e-2), Block (an ordered, typed,
  fixed-shape record — see §4), Ptr (opaque heap handle), Unknown (produced by
  stack shufflers; bypasses type checks). Mixed int/float math promotes to float.
- Strings: "Hi" expands to a Block of ASCII scalars, e.g. [ 72 105 ].
- Comments: `{` and `}` as standalone whitespace-isolated tokens.

═══ 2. Words and frames ═══
- Define: `#name ( inputs -- outputs ) body end`. Every signature MUST explicitly declare the type of each input and output parameter—either positionally (`#foo ( Ptr Scalar -- Scalar )`) or as tagged parameters (`#foo ( src:Ptr i:Scalar -- d:Scalar )`).
- Recognized type tags: Ptr, Block, Scalar, Record, Map, Unknown.
- Bind names with an arrow frame: `-> [ a b ] [ body ]`. The frame pops as many values as declared inputs, binding them for the body. The frame variables inherit the exact types declared in the signature positionally or via tags.
- BOTH brackets are required: `-> [ x ] [ x 1 + ]`. `-> [ x ] x 1 +` is a parse error.
- Scope: consecutive sibling frames inherit earlier unshadowed aliases; a
  trailing `cond` sees the active frame's aliases.
- Call a word by bare name (no `#`): `... fact_iter`. Define a helper BEFORE its
  caller.

═══ 3. Control flow ═══
- Conditional: `flag cond [ true-body ] else [ false-body ] ?`. The `cond`
  keyword is mandatory. Both branches MUST have identical net stack effect
  (same count AND same types out).
- `select` chooses a value with no branching: `vt vf flag select` -> vt if flag
  nonzero else vf. Both operands are always evaluated.
- No loop keyword. Write loops as tail-recursive words (self- or mutual-
  recursion in terminal position is optimized to iteration).
- Iterators over a Block:
    `[map|  idx val ctx | body ]`          body effect ( idx val -- val' )
    `[fold| idx acc val ctx | body from init ]`  body effect ( idx acc val -- acc' )
  `from init` sets the accumulator: `from 0` -> Scalar result, `from nil` ->
  Block result. Use `_` for an unused ctx. If ctx IS used, push it BEFORE the
  block: `ctx block [fold| ... ]` (loop pops block first, ctx second).

═══ 4. Data structures: Blocks and the access protocol ═══
A Block is an index-typed anonymous record: an ordered set of typed slots.
- STRUCTURALLY IMMUTABLE, value-mutable: you may replace a slot's value with a
  value of the SAME type. You may NOT change the shape (slot count) or a slot's
  type. Changing a slot's type is rejected by the checker.
- Homogeneous Block (all slots same type) = array/vector.
- Heterogeneous Block (mixed slot types) = record.

Access is a fixed per-type protocol (NOT one polymorphic operator). Each
collection type provides the same shape of words:
    <s>_get ( <s> key -- val )          keyed / static-slot read
    <s>_set ( <s> key val -- <s>' )     replace a slot value (same type only)
    <s>_at  ( <s> idx -- val )          integer-indexed read — OPTIONAL

- `_at` exists ONLY on homogeneous collections (arrays/lists/blocks), where the
  result type is known regardless of the index. Records do NOT provide `_at`;
  index a record and you have a nonexistent word. This makes the one
  undecidable case — computed index into mixed-type data — impossible to write.
- Use `_get` (static key/slot) for records; `_at` (integer index) for arrays.
- Pick the operation by the STRUCTURE you hold: `array_at`, `list_at`,
  `block_at` for sequences; `record_get`, `map_get` for keyed data. The word
  name states the type, so you never have to remember it.
- Mutation is tracked: a word that mutates an argument declares it. Do not rely
  on a value staying unchanged across a call that may mutate it.

═══ 5. Heap ═══
- `size hnew -> ptr`  allocate cells. `ptr idx hread -> val`. `val ptr idx hwrite`.
- Ptr is opaque: `ptr 1 +` is a type error. Compute the integer offset first,
  then pass it: `ptr offset hread`.
- Block access (`_at`/`_get`) and heap access (`hread`) are different: `_at`/
  `_get` index a Block value; `hread` reads a heap Ptr. They are NOT
  interchangeable.
- In-place swap: read BOTH cells before writing EITHER, or the first write
  destroys the value the second needs.

═══ 6. Zero-nesting rule ═══
- A bracketed block containing any operator, word call, or binding (frame, cond
  branch, iterator) is CODE. Code may not nest inside code beyond depth 1.
  Sibling blocks at the same depth are fine; a code block may not contain
  another code block. Extract inner loops/conditionals into named words.
- A bracketed block containing ONLY scalars/spaces/other data blocks is a DATA
  literal and may nest freely: `[ 1 [ 2 3 ] ]` is valid.

═══ 7. Worked examples (match these shapes) ═══
Each is complete and passes the checker.

Fold to a scalar:
    #sum ( block -- total )
      -> [ block ] [ block [fold| idx acc val _ | acc val + from 0 ] ]
    end

Map:
    #double_all ( block -- doubled )
      -> [ block ] [ block [map| idx val _ | val 2 * ] ]
    end

Fold building a block ('from nil'):
    #copy_reverse ( block -- reversed )
      -> [ block ] [ block [fold| idx acc val _ | val acc cons from nil ] ]
    end

Tail-recursive loop (helper defined first; call omits '#'; trailing cond sees frame):
    #fact_iter ( n acc -- r )
      -> [ n acc ] [ n 0 = ]
      cond [ acc ] else [ n 1 - n acc * fact_iter ] ?
    end
    #fact ( n -- r )
      -> [ n ] [ n 1 fact_iter ]
    end

Array vs record access (the distinction that matters):
    { array: homogeneous -> use _at }
    #third ( arr:Block -- v:Scalar ) -> [ arr ] [ arr 2 array_at ] end
    { record: mixed types -> use _get, never _at }
    #name_of ( rec:Record -- v:Scalar ) -> [ rec ] [ rec :name record_get ] end

Heap read/write:
    #store_read ( -- v:Scalar )
      3 hnew -> [ p ] [ 10 p 0 hwrite 20 p 1 hwrite p 1 hread ]
    end

═══ 8. Primitives ═══
Shufflers: dup ( x -- x x ) | drop ( x -- ) | swap ( x y -- y x ) |
  rot ( x y z -- y z x ) | over ( x y -- x y x ).
  (Track 2 does not carry types across shufflers — prefer frames to name values.)
Static-index shufflers: `roll` (move item at literal depth N to top),
  `pk` (copy item at literal depth N to top). INDEX MUST BE A LITERAL:
  `1 pk` ok; `idx pk` is a compile error.
Block build: cons ( x block -- block' ) | pair ( a b -- [a b] ) |
  nil ( -- [] ) | len ( block -- n ).
Math: + - * ( each -1 ) | / (floor if both int, else float) | \ (modulo).
Compare: = != > < ( each return 1/0 ). `>=` `<=` are in "util", not primitives.
Logic: and or ( eager, both operands evaluated — NOT short-circuit ) |
  not ( 1 if input is 0 ).
I/O: print_char ( ascii -- ) | print_int ( int -- ).

═══ 9. Standard library (import with `use "lexicon"`) ═══
Import at file top; names resolve only for imported lexicons.
util: reverse, length, nth (block idx -- val), sum, contains, filter_eq,
  index_of, concat, >= , <= .
strings: str_print, is_digit, is_space, is_upper, is_lower, int_to_str, print_line.
memory: hclear, hloop_fill, hloop_add, h_find_val.
array: arr_make, arr_size, arr_offset, arr_get, arr_set.
list: lst_make, lst_get, lst_set, lst_push.
map: map_make, map_get, map_set.
record: rec_make, rec_get, rec_set.

═══ 10. Hard rules (violations are rejected) ═══
- Reserved words — never use as a parameter/alias: use lexicon to from and or
  not cond else map fold pk roll select nil cons pair end dup drop swap rot over
  fill len seed rand exp log pow sqrt abs max min bitand bitor bitxor bitshl
  bitshr bitnot hnew hread hwrite print_char print_int. If your natural name
  collides (exp, max, len...), rename (e, mx, n).
- Never shadow your own word names with a local alias.
- `roll`/`pk` take LITERAL indices only.
- `cond` branches must match in count and type.
- No code block nested inside a code block (depth-1 cap).
- `_at` only on homogeneous collections; never index a record.
- `_set` may replace a value with the same type only — never change shape/type.
- Pointers are opaque — no pointer arithmetic.
- and/or are eager — guard risky paths with `cond`, not `and`/`or`.

═══ 11. What the checker does and does NOT prove ═══
Passing means: parses, stack-balanced, coarse types consistent. It does NOT
mean correct — a checked word can still compute the wrong answer while being
perfectly balanced. Correctness is your responsibility; the checker only
guarantees the program is well-formed.
